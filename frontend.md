# Widget Behaviour Spec

Generated by running every flow in the approved artifacts. Build the widgets so each step shows exactly these messages, options, inputs and quick pills.

How to use this spec:
- **Bot says**: exact wording, word for word. Lines separated by " / " are line breaks inside one bubble; " // " separates bubbles.
- **Shows**: the buttons or picker added at that step. "-" means no new buttons (the patient types in the bar).
- **Typing bar**: the placeholder text; "country code +" means the country code selector appears inside the bar (IN +91 default).
- **Quick pills**: mini pills above the typing bar (Derma only).
- Dates and times in examples are relative to the day the spec was generated; the rules (closed days, past times hidden, Tuesday disabled) are what matter.
- Invalid inputs are included on purpose ("P", "12345", "priya@") to show the exact error messages.
- Use this file as the source for the mock backend (Step 8 in WIDGET-STEPS.md) and the Playwright tests (Step 10 in WIDGET-STEPS.md).
- Language: English only.

### Rules added after review (these override the example rows below)

- **Time slots are 15 minutes** (for example 9:30, 9:45, 10:00, 10:15). The time chips in the tables below show 30-minute steps from the mockups; build with 15-minute slots. Staff can change the slot length later in NEO CRM.
- **Date pickers**: a new booking or new reschedule date can be today up to 2 weeks ahead. Past dates and the clinic's closed days are disabled, and past times are hidden for today. Closed days: Neo Fertility none, Neo Follicle Tuesday, Derma Solutions Tuesday. For "Which date is your appointment booked for?" the picker allows both previous and future dates, from 2 months back up to 2 weeks ahead (closed days stay disabled). The last slot of the day starts 30 minutes before closing.
- **Country code** in the phone step is changeable (IN +91 default). India needs 10 digits starting with 6 to 9; other countries 6 to 12 digits. Otherwise the error is "That number does not look right. Please check and enter it again."
- **Cancel and reschedule, no OTP**: the backend checks the name and contact number (or email) against existing bookings. If they match, the request is linked to that booking. If they do not match, the request is still sent to clinic staff, marked "No matching booking", for manual approval. In both cases the patient sees the same confirmation message shown in the tables below.
- **Derma Call Back** works the same as Navya and Arya (name, number, reason, confirmation). The table below has been corrected.
